# GitHub Pages 上传说明

本包已经编译，包含网页代码、模型内嵌贴图、Draco 解码器、三篇正文及海螺配图，不需要安装 npm。

1. 解压 ZIP。
2. 将解压后的全部内容上传至 Snail_Girl_Folktale 仓库根目录。index.html 必须位于仓库根目录，不要上传 ZIP 本身，也不要多套一层文件夹。
3. 替换同名文件并上传新增 assets 和 readings/images 文件，保留目录结构。
4. 如果 Pages 还未设置，使用 Deploy from a branch，选择上传所在分支和 /(root)。
5. 等待 GitHub Pages 部署成功后访问：
   https://sofiajiayihuang.github.io/Snail_Girl_Folktale/

本地请通过 HTTP 服务器预览，不能直接双击 file:// 的 index.html。
